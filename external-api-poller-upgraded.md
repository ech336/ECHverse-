# External API Poller

## Overview
This skill provides capabilities for polling external REST APIs and dispatching payloads for clearing and settlement tasks.

## Workflows
- **State Polling**: Use to verify status of external endpoints.
- **Payload Dispatch**: Use to POST data for automated settlement.

## Usage
Execute the bundled script: `/scripts/dispatch.sh`
