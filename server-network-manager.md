# Server Network Manager

This skill helps you manage network settings and perform basic network reconnaissance.

## Manage Server Configuration

Use this to set the receiving server URL or update the target IP.

## Perform Nmap Scan

Use this to perform Nmap scans on the configured target IP.

```bash
nmap -sV $NMAP_TARGET_IP
```
